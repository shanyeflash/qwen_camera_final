## ✨ 核心特色

- ✅ **启用控制**：可随时关闭相机控制
- 🎯 **相机模式**：4种智能拍摄模式
- 📊 **对称滑块**：所有移动滑块中间值为0，左右对称
- 🚀 **智能输出**：数值为0时不输出提示词

## 🎮 控制说明

### 基本设置
- **启用控制**：开启/关闭相机控制功能
- **相机模式**：标准模式、人物模式、产品模式、场景模式

### 移动控制 (-100到100)
- **前后移动**：负值=向后移动，正值=向前移动
- **左右移动**：负值=向左移动，正值=向右移动  
- **上下移动**：负值=向下移动，正值=向上移动

### 旋转控制
- **左右旋转**：-180°到+180°（负值=向右，正值=向左）
- **上下倾斜**：-90°到+90°（负值=向下，正值=向上）

### 镜头类型
- 标准镜头、广角镜头、俯视镜头、仰视镜头
- 特写镜头、微距镜头、近景镜头、远景镜头

## 🚀 快速使用

1. **添加节点**：搜索"QWEN相机控制"
2. **选择模式**：根据拍摄内容选择相机模式
3. **调整参数**：
   - 移动控制：向左拖动为负值，向右拖动为正值
   - 旋转控制：负值向右/下，正值向左/上
4. **连接输出**：将"提示词"连接到提示词输入
